# LiveCoinWatch Clone

This project is a frontend-only clone of [LiveCoinWatch](https://www.livecoinwatch.com/), a popular cryptocurrency tracking website. It provides a visually similar experience to the original site, with mock data to simulate real-time cryptocurrency market information.

## Features

- **Market Overview**: Display of key market metrics like total market cap, 24h volume, and market changes
- **Price Charts**: Interactive charts showing cryptocurrency price history with multiple time frames
- **Top Cryptocurrencies Table**: Sortable table of top cryptocurrencies with key metrics
- **Coin Detail Pages**: Detailed information about individual cryptocurrencies
- **Dark Mode**: Toggle between light and dark themes
- **Responsive Design**: Works on mobile, tablet, and desktop devices

## Technology Stack

- **React**: Frontend UI library
- **React Router**: For navigation and routing
- **Tailwind CSS**: For styling and responsive design
- **Recharts**: For interactive data visualization
- **React Icons**: For UI icons

## Getting Started

To run this project locally:

1. Clone the repository
2. Navigate to the frontend directory
3. Install dependencies:
   ```
   yarn install
   ```
4. Start the development server:
   ```
   yarn start
   ```
5. Open your browser to `http://localhost:3000`

## Project Structure

- `/src/components`: Reusable UI components
- `/src/pages`: Page components for different routes
- `/src/data`: Mock data to simulate cryptocurrency market information
- `/public`: Static assets

## Notes

- This is a frontend-only implementation with mock data
- All cryptocurrency information is simulated for demonstration purposes
- The application can be expanded with real API integration in the future
